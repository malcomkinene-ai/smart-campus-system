# Smart Campus Student Management System

A centralized Java-based academic information portal built using Spring Boot, SQLite, HTML5, CSS3, and Bootstrap.

## Features
- **Admin Dashboard**: Register users (Students/Lecturers), create courses, and assign lecturers to courses.
- **Lecturer Dashboard**: View assigned courses, track student attendance, and record coursework/examination marks.
- **Student Portal**: Self-enroll in courses, view attendance history, check course grades, and export academic transcripts.

## Prerequisites
- Java JDK 17 or higher
- Apache Maven
